# ReTrak 🛒

A Walmart-inspired e-commerce platform enabling buying and selling for suppliers, traders, and consumers. Built with Rust backend and Next.js frontend.

## 🚀 Features

- Multi-vendor marketplace with inventory management
- Batch processing and financial tracking
- Role-based access for farmers, traders, and suppliers
- Real-time stock tracking and production management

## 🛠️ Tech Stack

**Backend**: Rust (Axum, SeaORM, PostgreSQL)  
**Frontend**: Next.js 15, TypeScript, Tailwind CSS

## 🚀 Getting Started

### Backend Setup
```bash
cd rjagro
cargo build
cargo run
```

### Frontend Setup
```bash
cd rjagro/rjagro_frontend
npm install
npm run dev
```
